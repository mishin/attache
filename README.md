# Attache

Автономное однофайловое веб-приложение для сборки исходников проекта в один (или несколько) текстовых файлов для передачи в LLM (Gemini, DeepSeek, ChatGPT, Claude и др.).

Главный файл приложения — [`attache.html`](attache.html) (версия **v10.0**). Для истории в репозитории также сохранён исходный файл [`bundler_v9.7.html`](bundler_v9.7.html).

## Возможности

- **Полностью локальная работа без сервера и зависимостей** — всё в одном HTML-файле; файлы никуда не отправляются.
- **Три способа загрузки проекта**:
  - `showDirectoryPicker()` (Chromium) — быстрое чтение без перебора игнорируемых папок, список недавних проектов в IndexedDB и обновление кнопкой `⟳ Обновить` с сохранением отметок;
  - классический выбор папки (`<input webkitdirectory>`);
  - перетаскивание папки/файлов в любое место окна.
- **Фильтрация и `.gitignore`**:
  - встроенные пресеты (`Android / Kotlin`, `Java / JVM`, `Web / TS / JS`, `Python`, `Rust`, `Go / C++`, `Все текстовые`) и пользовательские пресеты;
  - шаблоны игнорируемых путей и расширений, скрытые файлы, лимит размера файла, детектор бинарных файлов и кодировок (`UTF-8` / `UTF-16` BOM);
  - поддержка вложенных `.gitignore` (`!исключения`, `**`, правила только для папок) и отчёт о пропущенных файлах.
- **Поиск и управление списком**:
  - язык фильтра-поиска: `слово`, `-исключение`, `c:текст` (по содержимому), `ext:kt`, `size>10kb`, `tokens<500`, `secret`;
  - плоский список с сортировкой по пути/токенам/размеру и интерактивное дерево папок с трёхуровневыми чекбоксами;
  - импорт и экспорт списка путей (`.txt`), горячие клавиши (`/`, `↑`/`↓`, `Пробел`, `Enter`, `←`/`→`, `Ctrl+Enter`).
- **Контроль секретов и лимитов контекста**:
  - предупреждение о строках, похожих на ключи и пароли (AWS, Google API, GitHub, OpenAI/Anthropic, Slack, Stripe, Telegram, приватные ключи, JWT и др.) без вывода самих значений в интерфейс;
  - оценка токенов (с учётом кириллицы/CJK и формата файла), шкала заполнения контекста модели и автоматическая разбивка на части (по лимиту модели 80%, по числу токенов или по мегабайтам).
- **Предпросмотр и оптимизация вывода**:
  - просмотр с подсветкой синтаксиса, переносом строк и навигацией между файлами;
  - нумерация строк, удаление комментариев (с опциональным сохранением doc-комментариев `/** */` и `///`) и режим «Как в итоге»;
  - встроенные шаблоны инструкций/промптов (`Java + Elasticsearch`, `Android / Kotlin`, `Code Review`, `Архитектура`) и собственный промпт в `<instructions>` с учётом токенов;
  - тёмная, светлая и системная (`Авто`) темы оформления.

## Использование

Откройте [`attache.html`](attache.html) напрямую в браузере (для полного API выбора папок в Chromium рекомендуется открывать через локальный сервер, например `python3 -m http.server`, или через GitHub Pages — [`index.html`](index.html) перенаправляет на `attache.html`).

## Тесты

Для запуска тестов требуется **Node.js** (проверено на v22) и для E2E — установленный Chrome/Chromium (внешних npm-зависимостей нет):

```bash
node tests/core.test.mjs
node tests/e2e.mjs
```
